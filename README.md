# rose-atelier
# Rose Atelier 🌹

Spring Boot・MySQL・Pythonを用いて制作した、バラ専門の注文・在庫管理アプリです。

## 使用技術

* Java
* Spring Boot
* MySQL
* Thymeleaf
* Python
* pandas
* matplotlib

## 主な機能

* 品種登録
* 在庫管理
* 注文機能
* カート・Checkout
* 廃棄登録
* 注文履歴
* Pythonによる売上分析

## 工夫した点

* 画像アップロード機能
* 在庫状態の自動更新
* 注文履歴データの分析グラフ化

## Python分析

注文履歴CSVを利用し、品種別売上ランキングを可視化。

## 制作目的

色・香り・雰囲気からバラを選べる、視覚的な注文体験をテーマに制作しました。
